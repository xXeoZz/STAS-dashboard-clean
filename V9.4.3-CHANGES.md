# STAS Dashboard v9.4.3

## Withings reliability fix

- Added pagination for Withings `getmeas` responses.
- Fetches additional pages while Withings reports more data.
- Merges multiple Withings measurement groups from the same date instead of keeping only one group.
- Preserves the newest value for each body metric when several measurements exist on one day.
- Diagnostics now report:
  - pages fetched
  - measurement groups fetched
  - newest raw Withings measurement timestamp
- Removed stale Basic Auth placeholders from `.env.example`.

All v9.4.2 dashboard UI and cycling fixes are otherwise unchanged.
